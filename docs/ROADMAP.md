## Журнал архитектурных решений (ADR)

- **ADR-001 (2026-11-21):** Нативный Android (Kotlin + Jetpack Compose, offline-first Room) вместо PWA/Expo ради гарантированной надёжности локальных уведомлений (`AlarmManager`), виджетов `Glance` и плавного Material 3 UX.
- **ADR-002 (2026-11-21):** Бесплатный Supabase (PostgreSQL + RLS) с клиентским E2EE по единому паролю (`PBKDF2-HMAC-SHA256 600k` + `HKDF-SHA256` + `AES-256-GCM` + wrapped `DEK`) — нулевые знания сервера и полная совместимость с `Web Crypto API` для будущей веб-версии.
- **ADR-003 (2026-11-21):** Собственные векторные Canvas-графики вместо сторонних библиотек — нулевой риск поломок при обновлениях Compose BOM и переиспользование геометрии в PDF-генераторе.
- **ADR-004 (2026-11-21):** Фокус на чистом трекере настроения (4 вкладки, без тяжёлых таблиц анамнеза и анализов), чтобы продукт оставался лёгким и универсальным для публикации.
- **ADR-005 (2026-11-21):** Локальный стек данных Этапа 1 — Room `2.8.4` (с экспортом схемы `app/schemas/`), Hilt `2.59.2`, KSP `2.3.6` и `kotlinx-serialization-json 1.11.0` поверх AGP `9.0.1` + Kotlin `2.3.20`; чистый Kotlin-слой `domain/` изолирован от Android/Room и покрыт быстрыми JVM-тестами, а JSON v1 поддерживает режимы импорта `MERGE` (LWW по `updatedAt` с дедупликацией дат) и `REPLACE`.
- **ADR-006 (2026-11-21):** Вкладка «Дневник» (Этап 2) построена на однонаправленном потоке данных (`StateFlow<DiaryUiState>` + `DiaryIntent`) в `@HiltViewModel DiaryViewModel` с инъекцией `java.time.Clock` для детерминированных JVM-тестов; конструктор сна переиспользует `SleepDurationCalculator` (отрезки с переходом через полночь и вычетами бодрствования + ручной ввод длительности), а живой бейдж «Смешанный день» делегирует расчёт в `AnalyticsCalculator.isMixedDay`.
- **ADR-007 (2026-11-21):** Вкладки «Обзор» и «Шкалы» (Этап 3) выносят расчёт координат графиков (`ChartGeometry`, `OverviewChartData`, `ScaleTrendPoint`) и построение сетки календаря Пн–Вс (`CalendarMonthBuilder`) в чистый Kotlin-слой `domain/` для переиспользования в PDF-генераторе (Этап 5) и быстрого покрытия JVM-тестами; три интерактивных векторных графика (`Настроение`, `Энергия + Сон с порогом < 6 ч`, `Тревога + Раздражительность`) и график динамики шкал реализованы на нативном Compose `Canvas` с `TextMeasurer` и горизонтальным скраббингом без перехвата вертикальной прокрутки.
