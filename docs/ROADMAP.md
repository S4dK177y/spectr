## Журнал архитектурных решений (ADR)

- **ADR-001 (2026-11-21):** Нативный Android (Kotlin + Jetpack Compose, offline-first Room) вместо PWA/Expo ради гарантированной надёжности локальных уведомлений (`AlarmManager`), виджетов `Glance` и плавного Material 3 UX.
- **ADR-002 (2026-11-21):** Бесплатный Supabase (PostgreSQL + RLS) с клиентским E2EE по единому паролю (`PBKDF2-HMAC-SHA256 600k` + `HKDF-SHA256` + `AES-256-GCM` + wrapped `DEK`) — нулевые знания сервера и полная совместимость с `Web Crypto API` для будущей веб-версии.
- **ADR-003 (2026-11-21):** Собственные векторные Canvas-графики вместо сторонних библиотек — нулевой риск поломок при обновлениях Compose BOM и переиспользование геометрии в PDF-генераторе.
- **ADR-004 (2026-11-21):** Фокус на чистом трекере настроения (4 вкладки, без тяжёлых таблиц анамнеза и анализов), чтобы продукт оставался лёгким и универсальным для публикации.
