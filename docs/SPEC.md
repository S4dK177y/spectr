# Spectr — Продуктовая спецификация

Актуальная продуктовая спецификация Android-приложения **Spectr**, согласованная на этапе проектирования (`/grill-me`).

---

## 1. Назначение и позиционирование

- **Название:** `Spectr` (`app.spectr.mood`).
- **Целевая платформа (Фаза 1):** нативный Android (`minSdk = 26`, тестирование на Pixel 7 Pro).
- **Целевая платформа (Фаза 2):** лёгкая веб-версия для ПК (CachyOS / любая ОС) поверх той же зашифрованной базы Supabase.
- **Характер продукта:** приватный, нейтральный по внешнему виду и клинически полезный трекер настроения, готовый к публикации как open-source проект на GitHub и использованию любым человеком (личные данные никогда не вшиваются в код).

---

## 2. Структура экранов (4 вкладки нижней навигации)

### Вкладка 1: «Дневник»
- Переключатель даты в шапке: `← Вчера | Сегодня` + выбор любой даты (стандартные календарные сутки без скрытых автосдвигов).
- **«Итог дня» (1 запись на дату)** — один плавный прокручиваемый экран из 4 карточек:
  1. **Настроение и фон:** шкала `-5 .. +5` с кратким описанием уровня, выбор `Динамики за день` (*Ровно / Утром хуже / Вечером хуже / Ночью хуже / Качели за день*) и кнопка подсказки `(?)` (включая важное правило не ставить `-5` автоматически за пассивные мысли о смерти).
  2. **Сон и энергия:** конструктор **1 или нескольких отрезков сна** (поддержка разбитого сна, напр. `22:00–01:30, 09:00–12:30`, вычет ночных пробуждений и авторасчёт чистых часов; плюс возможность указать часы вручную) и ползунок `Энергия (0–10)`.
  3. **Тревога, раздражительность и симптомы:** ползунки `Тревога (0–10)`, `Раздражительность (0–10)` + **7 мультивыборных чипов симптомов** с подсказками `(?)` («когда ставить / не ставить»):
     - Апатия / нет радости
     - Самокритика / вина
     - Туман / фокус
     - Пищевой срыв
     - Мысли о смерти
     - Гиперфикс / идеи
     - Ускор. мысли
     - Автоматический бейдж **«Смешанный день»**.
  4. **Детали и заметка:** `Алкоголь` (*Нет / Немного (повод) / Много (повод) / На стрессе / спаде*), `Лекарства` (психотропные: *Не назначены / Принял по схеме / Принял (есть побочки) / Пропуск (забыл) / Пропуск из-за побочек*) и свободная `Заметка за день`.
- **«Отметки момента» (опционально, 0..N за день):** быстрая 5-секундная фиксация в любое время суток с точным временем (`mood`, опционально `energy`, `anxiety`, `irritability`, короткая фраза). Вечером отображаются сверху экрана «Итог дня» как ориентир.

### Вкладка 2: «Обзор»
- **Помесячный цветной календарь настроения** (сетка Пн–Вс, выбор месяца и года, тап по дню открывает запись).
- **3 интерактивных графика** (переключатель периода: `14 дн. / 30 дн. / 90 дн. / Всё время`):
  1. Кривая настроения (`-5 .. +5`).
  2. Энергия (`0–10`) и Сон (часы) с порогом недосыпа `< 6 ч`.
  3. Тревога и Раздражительность (`0–10`).
- **Сводка KPI (14 метрик) и ключевые маркеры:** заполнено дней, среднее настроение, размах мин/макс, спад/норма/подъём, средние энергия/сон/тревога/раздражительность, выраженный спад (`≤ -2`), выраженный подъём (`≥ +2`), смешанные дни, недосып (`< 6 ч`), качели внутри дня, высокая тревога/раздраж. (`≥ 7`), мысли о смерти, пищевые срывы, гиперфикс, алкоголь, побочки.

### Вкладка 3: «Шкалы»
- **PHQ-9** (14 дней, `0–27`), **GAD-7** (14 дней, `0–21`), **ASRM** (7 дней, `0–20`).
- Автоматический пересчёт по дневнику + экран подтверждения и сохранения «Подтверждённого замера» с датой + история замеров.

### Вкладка 4: «Ещё»
- **Экспорт PDF для врача:** выбор периода (`14 / 30 / 90 дней / свой`), векторная стр. 1 (KPI + маркеры + шкалы авто/подтверждённые + календарь + 3 графика), опциональные тумблеры *«Добавить таблицу по дням»* и *«Включить личные заметки и моменты»*.
- **«Режим показа врачу» прямо с экрана телефона:** чистый экран «только для чтения» без кнопок редактирования и со скрытием личных заметок.
- **Справочник** (шкала `-5..+5`, правила заполнения, критерии 7 галочек).
- **Настройки:** темы, уведомления, биометрия/PIN и `FLAG_SECURE`, облачная синхронизация Supabase (вход/регистрация или локальный режим), резервное копирование (JSON/CSV экспорт и импорт).

## 3. Уведомления и виджет

- **Надёжные уведомления (`AlarmManager` exact alarms + `BOOT_COMPLETED`):**
  - 1 главное настраиваемое вечернее напоминание (по умолчанию `22:00`).
  - Умная отмена, если «Итог дня» уже заполнен сегодня.
  - Кнопки в шторке: `Заполнить день` и `Отложить (+1 ч)`.
  - Нейтральный текст на экране блокировки.
  - Периодическое напоминание раз в 14 дней сверить шкалы PHQ-9 / GAD-7 / ASRM.
- **Виджет на рабочий стол (`Jetpack Glance`):** статус дня, 7-дневная полоска настроения и быстрые кнопки `+ Момент` и `Итог дня`.

---

## 4. Темы оформления

- **Material 3 / Material You** (современные гайдлайны Google).
- **Режим:** Системный / Светлый / Тёмный / Чистый чёрный (AMOLED).
- **Палитра:** `Pixel Dynamic Color` (по умолчанию на Android 12+) + встроенные пресеты: *Спокойный минимализм*, *Тёплая бумага / природа*, *Мягкий сланец*.
- Семантическая палитра шкалы `-5..+5` (спокойные холодные → нейтральный → мягкие тёплые) остаётся однозначной в любой теме.

## 5. Задел на будущие версии (после v1.0)

1. Локальные инсайты и корреляции (сон ↔ настроение, дни недели, триггеры).
2. Интеграция с **Health Connect** (автоподхват сна и шагов).
3. Дополнительные клинические опросники поверх универсальной таблицы шкал.
4. Расширенный трекер лекарств (схемы приёма, дозировки, напоминания, побочки).
5. Опциональный ИИ-аналитик (строго по явному запросу пользователя).
